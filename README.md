✋ Sign Language Recognition

A deep learning-based system that recognizes hand gestures from webcam input and translates them into readable text. This project is designed to assist individuals with hearing or speech impairments, enabling gesture-based communication in real-time.

📌 Project Highlights

1) Real-time Sign Detection: Utilizes a Convolutional Neural Network (CNN) to identify hand gestures accurately.
2) Webcam Input Processing: Captures live gestures using OpenCV.
3) Trained on Gesture Datasets: Robust model trained on large gesture image datasets for high accuracy.
4) Text Overlay Display: Automatically displays the predicted sign on-screen for immediate feedback.
5) User-Friendly Interface: Simple, interactive, and intuitive system for real-time communication.

🛠 Tech Stack
Python – Core programming language
TensorFlow – Deep learning model training and inference
OpenCV – Webcam input and image processing
NumPy – Numerical computations and array handling

⚡ How It Works

i) The webcam captures your hand gesture in real-time.
ii) The image is pre-processed and fed into the trained CNN model.
iii) The model predicts the gesture and outputs the corresponding sign as text.
iv) The predicted sign is displayed on-screen using an overlay.

💡 Use Cases
1) Assistive communication for people with hearing or speech impairments
2) Gesture-based control for applications
