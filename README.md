# ✋ Sign Language Recognition  

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white) ![TensorFlow](https://img.shields.io/badge/TensorFlow-FF6F00?style=for-the-badge&logo=tensorflow&logoColor=white) ![OpenCV](https://img.shields.io/badge/OpenCV-5C3EE8?style=for-the-badge&logo=opencv&logoColor=white)  

A **deep learning-based system** that recognizes hand gestures from webcam input and translates them into **readable text**. Designed to assist individuals with **hearing or speech impairments**, enabling **gesture-based communication in real-time**.  

---

## 📌 Project Highlights

- 🔍 **Real-time Sign Detection:** Uses a CNN for accurate gesture recognition  
- 🎥 **Webcam Input Processing:** Captures live hand gestures using OpenCV  
- 🧠 **Trained on Gesture Datasets:** Robust model trained for high accuracy  
- 🖥️ **Text Overlay Display:** Displays predicted signs immediately on-screen  
- 👩‍💻 **User-Friendly Interface:** Simple, interactive, and intuitive  

---

## 🛠 Tech Stack

- **Python** – Core programming language  
- **TensorFlow** – Deep learning model training and inference  
- **OpenCV** – Webcam input and image processing  
- **NumPy** – Numerical computations and array handling  

---

## ⚡ How It Works

1. Webcam captures your hand gesture in real-time  
2. Image is pre-processed and fed into the CNN model  
3. Model predicts the gesture and outputs the corresponding sign as text  
4. Predicted sign is displayed on-screen using a live overlay  

---

## 💡 Use Cases

- Assistive communication for people with **hearing or speech impairments**  
- Gesture-based control for applications  
- Educational tools to learn **sign language**
